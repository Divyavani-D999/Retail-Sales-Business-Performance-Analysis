# Retail Sales & Business Performance Analysis
Project Overview
This is an independent data analysis project using a publicly available retail sales dataset downloaded from Kaggle.
The project explores retail sales and business performance across the United States and Canada, covering the period 2023–2026.
Using Microsoft Excel, the analysis examines sales trends, profitability, discount effectiveness, shipping performance, customer purchasing patterns, and regional performance.
The objective is to transform raw transactional data into meaningful business insights through data cleaning, exploratory analysis, PivotTables, calculated measures, and interactive dashboards.
Tools & Technologies
•	Microsoft Excel
•	Power Query
•	PivotTables and PivotCharts
•	Excel formulas and calculated measures
•	Data validation and dropdown filters
•	VBA for dashboard interactivity
Project Scope
•	Overall Business Performance Analysis
•	Regional Sales and Profitability Analysis
•	Customer Behaviour Analysis
Dataset Source: Kaggle (publicly available dataset)
Project Type: Independent Portfolio Project
